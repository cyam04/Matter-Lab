About MatterLab

An interactive, visual chemistry learning platform for Class 6–10 students. Runs entirely in the browser — no installation, no login required.

v4.0 Open Educational No Internet for Simulator
🎯 What MatterLab Does
  • 2D Canvas particle physics simulator for Phase Changes, Diffusion, and Solutions (Tyndall Effect)
  • 50+ real substances (15 solids, 15 liquids, 20 gases) with accurate phase data
  • NCERT-aligned theory notes for Class 6–10
  • 10 guided virtual experiments with full procedures and observation tables
  • Topic-wise MCQ quizzes (40+ questions) with instant feedback
  • Student progress dashboard with achievement badges (localStorage)
  • Hinglish / English language toggle for Indian students
  • Teacher/Classroom mode (Fullscreen, Smart Board optimised)
🛠️ Technology Used
  • HTML5 Canvas 2D API — Particle physics engine (no external libraries)
  • Vanilla JavaScript (ES6+) — All simulation logic and UI
  • CSS3 — Glassmorphism, animations, responsive layout
  • Google Fonts — Inter, Nunito, JetBrains Mono
  • localStorage API — Student progress tracking
  • No frameworks, no dependencies — runs instantly offline
  • ARIA labels — Accessibility for screen readers

👩‍🏫 Teacher Guide
  • Classroom Setup: Open on projector/Smart Board, press F for Fullscreen mode
  • States of Matter (Tab 1): Select substance → move temperature slider → observe live phase change with AHA box explanations
  • Diffusion (Tab 2): Remove barrier → watch KMnO₄-style diffusion with temperature control
  • Solutions (Tab 3): Toggle between Solution/Colloid/Suspension → use laser to demonstrate Tyndall Effect
  • Language: Use HI toggle for Hinglish mode to support regional students
  • Quiz: Assign specific topic quizzes as pre/post lesson assessment

⚠️ Important Disclaimer

MatterLab is an educational simulation tool designed to visually illustrate chemistry concepts for Class 6–10 students. Please note:
  • Particle simulations are simplified models for educational purposes and do not accurately represent real atomic/molecular behaviour at the quantum level.
  • Phase change temperatures shown in the simulator are scaled for demonstration and may not match real-world values exactly.
  • All chemistry content is derived from NCERT textbooks (Class 6–10) for educational reference only — no copyright infringement is intended.
  • The quiz questions are created for educational assessment purposes and are not official examination questions.
  • Always refer to your school textbooks and teacher guidance for examination preparation.
  • All student progress data is stored locally in your browser (localStorage) — no data is sent to any server.
